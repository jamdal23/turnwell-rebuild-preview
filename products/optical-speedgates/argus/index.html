Argus Sensor Barriers

Security can be beautiful. No other turnstile offers the versatility in design elements and security features of the Argus sensor barriers. Available in three models, they not only secure a supervised entrance area but integrate seamlessly into the surrounding environment — from short basic versions to exquisite objects with sophisticated sensors.

The modular design offers an almost endless array of colors and materials for handrails, side and profile parts, drives, and door leaves. Argus barriers complement any reception room: as a modern design element, a subtle functional unit, or a bold statement. Users are directed by lights, and passage widths from 25” up to 39” provide comfortable accessibility. For added security, swinging barriers can be up to 71” tall.

Key features
  • ✓ Variable passage widths: 25” to 39”
  • ✓ Variable door-leaf heights: 39”, 47”, 63”, or 71”
  • ✓ Works with any card reader using dry contacts
  • ✓ Customizable ambient lighting
  • ✓ Modular design, endless finishes
